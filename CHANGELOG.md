# Changelog

All notable changes to this project will be documented in this file.

The format is inspired by **Keep a Changelog** and this project follows **Semantic Versioning** once public releases begin.

---

## [0.1.0] - 2026-07-25

### Added
- Runtime Express route scanner
- Nested router traversal (recursive)
- Route parameter detection
- Array path support  
- Middleware and handler extraction
- CLI scanner (`@routeui/cli`)
- 21 unit and integration tests
- 6 example applications

---

## Release Notes

### Versioning

Future releases will follow Semantic Versioning.

- **MAJOR** — Breaking API changes
- **MINOR** — New backwards-compatible features
- **PATCH** — Bug fixes and improvements

Example:

```text
1.0.0
│ │ │
│ │ └── Patch
│ └──── Minor
└────── Major
```
