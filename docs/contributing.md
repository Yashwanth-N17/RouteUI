## Quick Summary

1. **Setup:**

   ```bash
   git clone https://github.com/Yashwanth-N17/RouteUI.git
   cd RouteUI
   pnpm install
   pnpm build
   ```

2. **Testing:**

   ```bash
   pnpm test
   pnpm test:watch
   ```

3. **Formatting:**

   ```bash
   pnpm format
   ```

4. **Commits:** Follow [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat(core): ...`, `fix(cli): ...`, `docs: ...`).

For detailed instructions on monorepo commands, architecture, and adding features, read [`CONTRIBUTING.md`](../CONTRIBUTING.md).
